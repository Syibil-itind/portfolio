EXPERIMENTAL RESEARCH (2025) 100.000 Sampel Dataset
Python, Scikit-Learn, URL & Image Feature Extraction

Large-Scale QR Code Phishing Detection

Serangan phishing melalui kode QR (quishing) menyembunyikan tautan berbahaya di balik matriks visual sehingga sering melewati filter keamanan teks biasa. Riset eksperimen ini membangun dan mengevaluasi model klasifikasi Machine Learning menggunakan dataset berskala besar berjumlah 100.000 sampel untuk mendeteksi kode QR berbahaya secara akurat.

Kontribusi Utama Riset:
  • Membangun dan mengevaluasi model klasifikasi Machine Learning pada 100.000 sampel data eksperimen kode QR jinak maupun berbahaya.
  • Mengekstraksi dan melakukan prapemrosesan fitur kunci dari struktur URL maupun citra QR guna mencapai akurasi klasifikasi tinggi sekaligus menekan tingkat false positive.

Tahapan Pipeline Klasifikasi:

  1. 1. Kurasi 100.000 Sampel Eksperimen

    Pengumpulan dan penyeimbangan dataset kode QR sah dan berbahaya untuk pelatihan serta pengujian.

  2. 2. Ekstraksi Fitur URL & Citra

    Pengambilan fitur leksikal tautan, panjang domain, pola karakter abnormal, serta properti struktur matriks QR.

  3. 3. Evaluasi Akurasi & Minimasi False Positive

    Pengujian metrik presisi, recall, dan F1-score agar tautan valid tidak salah diblokir oleh model.

ADVERSARIAL ML RESEARCH (2026) PGD Defense & Biometric Security
PyTorch, CNN, Projected Gradient Descent (PGD)

Biometric Anti-Spoofing & Adversarial ML Robustness Research

Sistem autentikasi biometrik wajah rentan terhadap gangguan piksel halus (adversarial perturbations) yang tidak kasat mata bagi manusia namun mampu menipu jaringan saraf tiruan. Riset ini meneliti mekanisme pertahanan terhadap serangan Projected Gradient Descent (PGD) pada sistem facial anti-spoofing.

Kontribusi Utama Riset:
  • Meneliti mekanisme pertahanan terhadap serangan adversarial Projected Gradient Descent (PGD) pada sistem biometrik dan deteksi pemalsuan wajah.
  • Mengeksplorasi teknik mitigasi hibrida untuk melindungi arsitektur Computer Vision berbasis deep learning dari serangan injeksi dan manipulasi input.

Kerangka Evaluasi Ketahanan Model:

  1. 1. Simulasi Serangan PGD Iteratif

    Menguji kerentanan arsitektur CNN biometrik terhadap gangguan gradien terarah pada berbagai nilai epsilon.

  2. 2. Mitigasi Hibrida & Sanitasi Input

    Menggabungkan pelatihan adversarial dengan prapemrosesan fitur visual untuk meredam gangguan injeksi.

  3. 3. Verifikasi Ketahanan Anti-Spoofing

    Memastikan model tetap mampu membedakan wajah asli dan upaya spoofing di bawah tekanan serangan adversarial.

NETWORK SECURITY LAB TryHackMe, GNS3 & Parrot OS
Wireshark, Parrot OS, GNS3, Cisco Packet Tracer

Network Defense & Traffic Analysis Virtual Lab

Laboratorium jaringan virtual untuk mempraktikkan skenario ofensif dan defensif secara terukur. Mencakup inspeksi lalu lintas paket TCP/UDP secara langsung menggunakan Wireshark di Parrot OS serta perancangan topologi jaringan kelas enterprise di GNS3 dan Cisco Packet Tracer.

Cakupan Eksperimen Laboratorium:
  • Menjalankan skenario simulasi ofensif dan defensif, menganalisis lalu lintas TCP/UDP secara langsung serta anomali protokol dengan Wireshark di Parrot OS.
  • Mensimulasikan topologi jaringan enterprise, protokol routing, dan pengujian beban lalu lintas (DoS/DDoS stress-testing) di dalam lingkungan GNS3 dan Cisco.

Komponen Simulasi & Forensik:

  1. 1. Perancangan Topologi GNS3 & Cisco

    Konfigurasi subnetting, protokol routing, dan pembagian segmen jaringan virtual.

  2. 2. Simulasi Beban DoS/DDoS & Penetrasi

    Pengujian ketahanan layanan jaringan terhadap lonjakan paket abnormal dari host pengujian Parrot OS.

  3. 3. Forensik Paket dengan Wireshark

    Pembedahan header TCP/UDP, identifikasi pola anomali jabat tangan koneksi, dan penyusunan aturan mitigasi.
